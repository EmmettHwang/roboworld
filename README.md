## 2. 왜 청양인가

### 2-1. 청양군의 현재

| 지표 | 수치 |
| ------ | ------ |
| 인구 | **2만 9천 명대** (지속 감소) |
| 초고령화율 | **약 42%** |
| 연간 출생아 | **63명** |
| 연간 사망자 | **548명** |
| 국가 지정 | 행정안전부 **인구감소지역** (충남 9개 시군 중 하나) |

출생아 63명에 사망자 548명. 자연감소만으로 해마다 500명 가까이 줄어듭니다.
여기에 **청년 유출**이 겹칩니다. 비봉산업단지 조성이 표류하면서
지역에 남을 이유를 찾지 못한 청년층이 계속 빠져나가고 있습니다.

### 2-2. 문제의 진짜 원인

인구감소 대응이 대개 **출산 장려금**과 **일자리**에 집중되지만,
청양이 잃고 있는 것은 그보다 앞단입니다.

> **아이를 낳을 수 없어서가 아니라, 아이를 키울 수 없어서 떠납니다.**

30~40대가 정주지를 결정할 때 가장 먼저 보는 것은 **교육 환경**입니다.
학원도 체험시설도 없는 곳에서는, 일자리가 생겨도 가족은 따라오지 않습니다.
청년이 취업해도 결혼과 동시에 인근 도시로 이주하는 이유가 여기 있습니다.

### 2-3. 로보월드캠퍼스가 답하는 방식

| 청양의 문제 | 로보월드캠퍼스의 대응 |
| ------------- | ------------------------ |
| 교육 인프라 부재로 30~40대 유출 | 국어 · 영어 · 수학 정규 교육 + 메이커 교실을 군 내에서 제공 |
| 아이들이 갈 곳이 없음 | AI·로봇, 우주항공, 해저·공룡 체험관 — 주말마다 찾는 목적지 |
| 초고령화, 노년층 고립 | 합창 · 회화 · 웰니스 · 건강 등 평생교육으로 세대 통합 |
| 청년 일자리 부재 | 교육 · 전시 운영, 과학기술 인력, 상권 · 서비스 일자리 창출 |
| 외부 유입 동력 없음 | 세계 로봇 만들기 대회 — 연 1회 국제 방문 수요 |

핵심은 **연중 상시 수요**입니다. 축제형 관광은 며칠 반짝하고 끝나지만,
교육은 매주 다닙니다. 그래서 상권과 일자리가 계절을 타지 않습니다.

## 3. 비전

> **미래는 어느 날 갑자기 찾아오지 않습니다.**
> 아이들의 질문이 발견으로, 작은 호기심이 더 큰 가능성으로 이어질 때 시작됩니다.

로보월드캠퍼스는 교육 시설을 넘어, **배움과 문화, 산업과 공동체를 연결하는
미래 도시의 기반**을 지향합니다.

배움이 특정 시기 · 특정 장소에 갇히지 않고 **도시의 풍경**이 되게 하는 것,
그래서 일상이 곧 미래를 준비하는 과정이 되게 하는 것이 이 사업의 목표입니다.

## 5. 공간 구성

### 5-1. 부지 전략 — 폐교와 유휴공간 활용

**새로 짓지 않고, 비어 있는 것을 되살립니다.**

인구감소는 폐교를 남깁니다. 전국적으로 폐교재산 4,008개소 중
**376개소가 아직 활용되지 못한 채** 남아 있습니다. 청양군도 학생 수 감소로
문을 닫은 학교와 유휴 공공시설을 안고 있습니다.

로보월드캠퍼스는 이 공간들을 **1순위 후보지**로 검토합니다.

| 이유 | 내용 |
| ------ | ------ |
| **초기 투자비 절감** | 신축 대비 건축비를 크게 줄일 수 있습니다. 기금 심사에서 사업비 효율성은 핵심 평가 항목입니다 |
| **용도 전환이 자연스러움** | 이미 교실 · 강당 · 급식실을 갖춘 교육 시설입니다. 교육 프로그램을 그대로 얹을 수 있습니다 |
| **운동장 = 행사장** | 세계 로봇 만들기 대회의 야외 경기장 · 부스 공간으로 즉시 활용 가능합니다 |
| **주민 접근성** | 마을 한가운데 있고, 주민에게 이미 익숙한 장소입니다 |
| **제도적 뒷받침** | 교육부 · 행정안전부가 지자체 폐교 활용 가이드라인을 마련해 절차를 정비했습니다 |
| **상징성** | 아이가 줄어 문을 닫은 학교가, 아이를 다시 부르는 공간이 됩니다 |

#### 활용 구상

- 폐교 본관 → 교육 시설 (교과 교실 · 메이커 교실 · 평생교육 강의실)
- 폐교 강당 → 소규모 체험관 · 다목적 홀
- 운동장 → 로봇대회 경기장 · 야외 행사 광장
- 유휴 공공시설 → 전시관 · 창업 공간 · 방문자 센터
- 신축은 대규모 몰입형 체험관 등 **꼭 필요한 시설로 한정**

> 청양군 내 폐교 위치 · 규모 · 소유 관계(교육청/군)는 **현장 조사가 필요**합니다.
> 충청남도교육청 폐교재산 활용 안내와 지방교육재정알리미에서 확인합니다.

| **폐교활용 지원** | 교육부 폐교 활용 연계 지원 | 폐교를 부지로 쓰면 건축비를 크게 줄여 **사업비 효율성** 확보 |
| **고향사랑기부제** | 지자체별 모금 | 로봇대회 · 체험관을 답례 콘텐츠로 활용 |
| **민간 투자** | — | 체험관 운영, 상업시설 임대, 기업 후원 |

> ⚠️ 위 금액은 **제도 전체 규모**이며, 청양군이 확보할 수 있는 금액이 아닙니다.
> 실제 확보액은 공모 경쟁과 심사 결과에 따라 결정됩니다.

### 9-2. 단계별 조달 구상

| 단계 | 내용 | 주 재원 |
| ------ | ------ | -------- |
| 1단계 | 기본구상 · 타당성 조사 | 지방소멸대응기금 (기초지원계정) |
| 2단계 | 부지 확보 (**폐교 우선 검토**) · 기반 조성 | 국비 · 도비 · 군비 매칭 + 폐교재산 대부 |
| 3단계 | 시설 건립 | 지역활성화 투자 펀드 (민관 공동) |
| 4단계 | 프로그램 운영 | 교육발전특구 특별교부금 + 자체 수익 |

### 9-3. 왜 심사에서 유리한가

지방소멸대응기금은 **"인구 유입 효과가 있는 사업"** 에 집중 투입하는 쪽으로
운용 기조가 옮겨가고 있습니다. 대부분의 지자체 사업이 시설 건립에 그쳐
"그래서 사람이 늘어납니까"라는 질문에 답하지 못하는 반면,
로보월드캠퍼스는 **교육 → 정주 → 일자리** 로 이어지는 인과를 제시할 수 있습니다.

지역활성화 투자 펀드 역시 인구감소지역 투자비율을 절반까지 끌어올린 상태여서,
청양군 소재 프로젝트라는 점 자체가 유리한 조건입니다.

여기에 **폐교 활용**이 더해지면 사업비가 크게 낮아집니다.
같은 예산으로 더 많은 것을 하겠다는 계획은 어느 심사에서든 강합니다.
