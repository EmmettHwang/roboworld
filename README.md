# 로보월드캠퍼스 · ROBOWORLD CAMPUS

> 교육과 체험, 문화와 산업이 하나의 일상으로 이어지는 곳
> **대한민국 미래 교육의 새로운 기준**

미래 교육 · 과학문화 체험 · 지역 산업을 한 부지에 묶은 **캠퍼스타운** 조성 사업입니다.
아이와 가족이 일상적으로 찾아와 보고, 만들고, 질문하는 열린 캠퍼스를 만들고,
그 방문 수요를 지역 상권과 일자리로 되돌리는 것을 목표로 합니다.

---

## 2. 비전

> **미래는 어느 날 갑자기 찾아오지 않습니다.**
> 아이들의 질문이 발견으로, 작은 호기심이 더 큰 가능성으로 이어질 때 시작됩니다.

로보월드캠퍼스는 교육 시설을 넘어, **배움과 문화, 산업과 공동체를 연결하는
미래 도시의 기반**을 지향합니다.

배움이 특정 시기·특정 장소에 갇히지 않고 **도시의 풍경**이 되게 하는 것,
그래서 일상이 곧 미래를 준비하는 과정이 되게 하는 것이 이 사업의 목표입니다.

## 3. 3대 축

| 축 | 핵심 | 내용 |
| ---- | ------ | ------ |
| **LEARN** — 배움 | 배움이 일상이 되는 캠퍼스 | 아동·청소년부터 중장년·시니어까지, 정해진 나이 없이 누구나 배우고 교류하는 열린 교육의 장 |
| **EXPERIENCE** — 체험 | 보고, 만들고, 질문하는 체험 | AI·로봇, 우주항공, 차세대 에너지, 해저·공룡까지 몰입형 체험으로 과학을 몸으로 이해 |
| **GROW TOGETHER** — 상생 | 지역과 함께 성장하는 산업 | 상권·서비스·전문 인력으로 이어지는 지역 경제 선순환 |

세 축은 분리된 사업이 아니라 **하나의 방문 동선** 안에서 이어집니다.
교육을 받으러 온 가족이 체험관을 돌고, 캠퍼스 상권에서 소비하고,
그 수요가 다시 지역 일자리를 만드는 구조입니다.

## 4. 공간 구성

### 4-1. 교육 시설

- 아동·청소년 교과 교육 (국어 · 영어 · 수학)
- 메이커 · 창작 교실
- 평생교육 강의실 (합창 · 회화 · 웰니스 · 건강)
- 스포츠 · 자기계발 시설 (체육관 · 필라테스/요가 스튜디오 · 멘토링 룸)

### 4-2. 미래 기술 체험관

| 체험관 | 콘셉트 | 주요 콘텐츠 |
| -------- | -------- | ------------- |
| **AI · 로봇 체험관** | AI와 로봇을 직접 만나 이해하는 미래 기술 | 휴머노이드 로봇 · AI 인터랙션 · 코딩 체험 |
| **우주 · 항공 영상 체험관** | 온 몸으로 경험하는 우주 | 몰입형 대형 영상 · 발사체/우주정거장 · 천체 관측 |
| **차세대 발전 기술 체험관** | 체험을 통해 쉽게 이해하는 에너지 발전 | 풍력·태양광 실험 · 스마트시티 설계 · 에너지 시뮬레이션 |

### 4-3. 몰입형 박물관

| 박물관 | 콘셉트 | 주요 콘텐츠 |
| -------- | -------- | ------------- |
| **해저 탐험 박물관** | 깊은 바다 속으로 들어가는 몰입 체험 | 심해 탐사 · 해양 생태 · 잠수정 시뮬레이터 |
| **공룡 테마 박물관** | 상상 속 세계를 생생한 배움의 공간으로 | 실물 크기 복원 · 고생대 생태 · 화석 발굴 체험 |

### 4-4. 캠퍼스 광장 · 상권

- 중앙 광장 (분수 · 야외 행사 공간)
- 캠퍼스 주변 상권 · 거리
- 카페 · 식음 · 서비스 시설

## 5. 교육 프로그램 체계

### 미래 세대 교육 (아동 · 청소년)

| 프로그램 | 지향 |
| ---------- | ------ |
| 국어 교육 | 읽고, 쓰고, 말하며 미래를 준비하는 힘 |
| 영어 교육 | 다른 언어로 대화하며 기르는 글로벌 역량 |
| 수학 교육 | 사고력과 창의수학으로 키우는 문제 해결 능력 |
| 메이커 · 창작 교실 | 직접 만들며 호기심을 결과물로 |

### 평생 교육 (성인 · 중장년 · 시니어)

| 프로그램 | 지향 |
| ---------- | ------ |
| 중장년 · 시니어 합창 교육 | 노래와 예술로 세대가 교류 |
| 시니어 회화(그림) 수업 | 표현의 즐거움과 일상의 여유 |
| 웰니스 · 스킨케어 수업 | 생활 속 건강 관리와 자기 돌봄 |
| 시니어 건강 수업 | 무리 없는 운동으로 건강한 일상 |

### 스포츠 · 자기계발

| 프로그램 | 지향 |
| ---------- | ------ |
| 청소년 일대일 멘토링 | 가까이에서 함께 고민하며 가능성을 찾기 |
| 그룹 자기계발 워크숍 | 협업 속에서 개인의 가능성을 공동체 성장으로 |
| 생활운동 수업 | 함께 몸을 움직이며 건강해지기 |
| 필라테스 · 요가 수업 | 호흡과 자세로 일상의 균형 회복 |

## 7. 지역 경제 파급

> **사람이 모이면 거리가 살아나고, 새로운 서비스와 일자리가 생겨납니다.**

| 영역 | 내용 |
| ------ | ------ |
| 캠퍼스 주변 상권 · 거리 | 방문객 흐름이 만드는 상권 활기 |
| 지역 카페 · 서비스 일자리 | 일상적 방문 수요 → 안정적 서비스 일자리 |
| 과학 기술 전문 인력 | 연구·전시·체험 운영을 뒷받침하는 기술 인력 정착 |
| 교육 · 행사 운영 인력 | 연중 이어지는 교육·행사가 만드는 운영 일자리 |

핵심은 **연중 상시 수요**입니다. 단발성 관광이 아니라 정기적으로 다니는 교육 수요가
있기 때문에 상권과 일자리가 계절을 타지 않습니다.

> 고용 창출 규모 · 경제 파급효과 추정치는 **정량 분석이 필요**합니다.
