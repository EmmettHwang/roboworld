만들 때 그대로 복사해 넣는 프롬프트 모음입니다.

- 행사명: **국제 로봇 페스티벌** (INTERNATIONAL ROBOT FESTIVAL)

- 프로그램: 로봇 배틀 아레나 · AI 챌린지 · 로보틱스 엑스포 · 메이커 워크숍

## 0. Gemini에 넣기 전에 — 6가지

### ① 문장으로 쓰세요

Gemini는 Midjourney와 문법이 다릅니다.
`cinematic, 35mm lens, high detail` 처럼 **단어를 콤마로 나열하면 잘 안 먹습니다.**
아래 프롬프트는 전부 **완전한 문장 서술형**으로 써 두었습니다. 그대로 쓰세요.

### ② `--ar 16:9` 같은 파라미터는 없습니다

Gemini에는 Midjourney식 플래그가 없습니다.
**종횡비는 화면 UI에서 16:9(가로형)로 고르세요.**
프롬프트에도 `The image is a widescreen 16:9 photograph.` 라고 한 문장 넣어두었습니다.

### ③ 한글 글자는 여전히 깨집니다

Imagen이 영문 짧은 단어는 제법 쓰지만 **한글은 아직 깨집니다.**
그래서 모든 프롬프트에 **"현수막은 글자 없는 단색"** 이라고 지시해 두었습니다.
문구는 받아온 뒤에 얹습니다 (6장 참조).

### ④ ⚠️ Veo는 소리까지 만듭니다

영상 프롬프트를 그냥 넣으면 **AI가 지어낸 영어 대사가 들어갑니다.**
나레이션을 따로 얹을 계획이므로, 모든 영상 프롬프트 끝에 이 문장을 넣었습니다.

```text
No spoken dialogue and no narration. Ambient event sound only.
No text, captions, or subtitles anywhere in the frame.
```

### ⑤ 안전 필터를 피하는 단어

`combat`, `battle`, `fight` 는 Gemini가 폭력으로 판단해 거부할 수 있습니다.
아래 프롬프트는 **`competition`, `match`, `contest`** 로 바꿔 두었습니다.
혹시 거부당하면 그 단어를 더 순화하세요.

### ⑥ 한국어로 넣어도 됩니다

Gemini는 한국어를 잘 알아듣습니다. 다만 **영어가 조금 더 정확합니다.**
각 항목에 한국어 요약을 함께 적어 두었으니, 영어가 거부당하거나
결과가 이상하면 한국어 쪽을 넣어 보세요.

## 7. 잘 안 나올 때

| 증상 | 해결 |
| ------ | ------ |
| 도시 배경이 나온다 | `small rural county, not a city` 를 문장 끝에 한 번 더 |
| 신축 건물처럼 보인다 | `The original school building must remain clearly recognisable.` 추가 |
| 글자가 깨져서 들어간다 | `Absolutely no letters or writing anywhere in the image.` 추가 |
| 얼굴·손이 뭉개진다 | 인물을 멀리 두거나 `seen from behind` / `hands only` 로 바꾸기 |
| 요청이 거부된다 | `competition` → `friendly match`, `robot contest` 로 완화 |
| 영상에 영어 대사가 들린다 | 4장의 마지막 두 문장이 빠졌는지 확인 |
| 비율이 안 맞는다 | 프롬프트가 아니라 **화면 UI에서 16:9 선택** |

1. 파일명을 용도가 드러나게 저장 — `fest-main.jpg`, `fest-arena.jpg` 처럼
2. **아래쪽 25%는 비워두면** 자막 얹기가 편합니다
3. 웹용은 가로 1200px · JPEG 품질 85 정도로 줄입니다
4. 영상은 1280×720 · H.264 · CRF 27 로 인코딩 (`tools/README.md` 참조)

이미지를 받아 오시면 웹사이트 로봇 페스티벌 섹션에 넣고,
문구 합성과 용량 최적화까지 해 드리겠습니다.
