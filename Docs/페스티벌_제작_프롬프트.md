# 국제 로봇 페스티벌 — Gemini 프롬프트

복사해서 Gemini에 그대로 붙여넣으세요. 한국어로 넣으면 됩니다.

---

## 시작 전에 딱 3가지

**1. 사람은 넣지 마세요.**
Gemini는 아이가 나오는 사진을 거의 다 거부합니다. 그래서 아래 프롬프트에는
사람이 없습니다. 로봇과 공간만 나옵니다. (사람 얼굴·손은 AI가 자주 망치기도 합니다)

**2. 비율은 화면에서 고르세요.**
프롬프트에 쓰지 말고, Gemini 화면에서 **가로형 16:9** 를 선택하세요.

**3. 글자는 나중에 얹습니다.**
AI는 한글을 못 씁니다. 프롬프트마다 "글자 없음"을 넣어 뒀습니다.
문구는 아래 5장에 있습니다.

## 1. 대표 이미지 ⭐

가장 중요한 한 장입니다. 이것부터 뽑으세요.

```text

흰색 행사 천막이 줄지어 있고 가운데에 원형 경기 무대가 있다.
가장자리에 여러 나라 국기. 옛 학교 건물이 그대로 남아 있고 유리로 증축되어 있다.
뒤로 낮은 산과 논밭. 늦은 오후 햇살. 글자 없음. 사실적인 사진.
```

**밤 버전** — 마지막 줄만 바꾸세요

```text

```

## 11. 안 나올 때

| 이럴 때 | 이렇게 |
| -------- | -------- |
| 거부당함 | 사람 관련 단어가 있는지 확인. 다 빼세요 |
| 도시처럼 나옴 | `도시가 아니라 시골 마을` 을 끝에 추가 |
| 새 건물처럼 나옴 | `옛 학교 건물 모습이 그대로 남아 있어야 한다` 추가 |
| 글자가 깨져 들어감 | `사진 안에 어떤 글자도 없어야 한다` 추가 |
| 비율이 안 맞음 | 프롬프트 말고 **화면에서 16:9 선택** |
